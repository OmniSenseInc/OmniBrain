== Cara pakai di VPS baru ==
1) git clone <repo> && cd repo
2) gabungkan bagian: cat *.part > bundel.enc
3) buka sandi   : openssl enc -d -aes-256-cbc -pbkdf2 -iter 200000 -in bundel.enc -out bundel.zip -pass env:MIGRASI_PASS
4) jalankan pulihkan.sh (lihat README_MIGRASI.md)
