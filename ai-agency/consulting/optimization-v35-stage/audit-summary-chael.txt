Hasil audit API OmniSense: 12 uji sintetis langsung ke endpoint Bynara tanpa Hermes/memory. Instruksi exact-output di system gagal dua kali, developer gagal, tetapi instruksi yang sama di user berhasil. Kasus bisnis di system dijawab sebagai kasus medis; kasus bisnis+JSON di user berhasil. Respons langsung mengaku byNara. Ini bukti masalah penerapan/penerusan role, bukan bukti pasti model masking atau model DeepSeek asli lemah. Upstream belum terverifikasi. Tidak ada konfigurasi/model/website produksi diubah dalam audit ini. Optimasi kode dan 108 tes sebelumnya tetap sah, tetapi bukan bukti kepatuhan model live. Pembekalan agent perlu menunggu jalur instruksi diperbaiki atau endpoint pengganti lolos uji.
